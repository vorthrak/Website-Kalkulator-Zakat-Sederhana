# Website Kalkulator Zakat Sederhana

Website ini dibuat menggunakan HTML, CSS, dan JavaScript sebagai alat bantu untuk menghitung zakat penghasilan. Proyek ini ditujukan untuk edukasi dan praktik pengembangan web dasar.

## 📌 Fitur Utama
- Input jumlah penghasilan
- Hitung zakat otomatis (2.5%)
- Menampilkan hasil zakat dengan tampilan yang responsif dan sederhana

## 🧩 Teknologi yang Digunakan
- HTML5
- CSS3 (Flexbox, Responsive)
- JavaScript (DOM Manipulation)

## 🚀 Cara Menjalankan
1. Clone repositori ini atau unduh zip-nya.
2. Buka `index.html` di browser (double-click atau drag ke tab browser).
3. Masukkan jumlah penghasilanmu, lalu klik tombol **Hitung**.
4. Hasil zakat akan muncul di bawahnya.
